# Ilustre Móveis — protótipo de landing page

Site estático (HTML + CSS + GSAP/ScrollTrigger), sem etapa de build.

- `index.html` — página completa
- `assets/` — fotos e bibliotecas (GSAP 3.12.5, ScrollTrigger)

## Deploy na Vercel
Importe o repositório em https://vercel.com/new com o preset **Other**, sem comando de build e sem diretório de saída.

> Protótipo de redesign, não é o site oficial da Ilustre Móveis. Página marcada como `noindex` e com aviso no topo.
> O formulário de orçamento ainda não envia dados — precisa ser ligado ao e-mail, CRM ou WhatsApp da loja.
